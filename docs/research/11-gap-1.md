# 11 — Gap 1: Dedalus^L, a formal semantics and provenance model for Dedalus with lattice-typed columns

Research gap report for **bloom-remake**. It closes FOLLOW-UP GAP 1 from FEATURES.md: the literature gives no formal
semantics or provenance model for Dedalus programs whose relations carry lattice values. The deliverables are:

1. a candidate **normative definition** of "Dedalus^L" (§3);
2. an analysis of which **theorems carry over**, and under which side conditions (§4);
3. **encodings** of the common lattices into ASP/clingo (VER-003) and FOL/EPR (VER-006) (§5);
4. a **provenance model** for lattice and aggregate values that LDFI and explain/whynot can use (§6);
5. **test programs** with exact per-tick states, ultimate models and LDFI minimal falsifiers (§7);
6. a MUST-IMPLEMENT CHECKLIST (§8).

Everything marked **[ours]** is an inference made for this report. It is not a claim from the literature. Some of
the inferences are backed by machine checks. I ran every expected result in §7 through a small reference simulator
written for this report (scratch code, not in the repository). The ASP encodings in §5.1 ran on **clingo 5.8.2**
and the FOL verification conditions in §5.2 ran on **Z3 4.16.0**. Each claim says which check backs it.

## 1. Executive summary

- **No published formal semantics exists for Bloom^L or for Dedalus with lattices.** Conway's dissertation says so
  directly: "the development of a formal model-theoretic semantics for BloomL remains a topic for future work"
  ([THESIS-NC] §3.2, p. 24). TPLP names aggregation as future work for its own framework ([TPLP] §6, p. 38).
  Datalog° leaves stable models with negation over semirings open ([DLO] §9). So §3 is our own construction,
  assembled from four pieces that are published:
  - the TPLP transition system and `pure(P)`;
  - Ross–Sagiv's lattice-ordered interpretations with a functional dependency on the cost argument ([RS] Defs 3.2–3.7);
  - Flix's cell and compactness model ([FLIX] §3.2);
  - Ross–Sagiv's "alternative stable model", which reduces only negative literals and keeps monotone aggregates ([RS] §5.5).
- **The core idea [ours]:** make *every* relation lattice-valued under its key functional dependency. A set relation
  is simply the case over 𝔹 = ({ff, tt}, ∨, ff). An instance becomes a finite map from cells to non-⊥ values. Then
  replace ∪ by the cellwise join ⊔ and ⊆ by ⊑. With that change, the TPLP local transition (§5.1.3) reads unchanged,
  and every set-only program keeps its TPLP meaning exactly.
- **Decisions this report makes normative (proposed as new CRs):**
  1. Derivations for the same key **merge**; they do not conflict. This is Bloom^L's rule, not Ross–Sagiv's
     cost-consistency requirement.
  2. **Merge at the sender.** Each (addressee, relation, key) produces one message per send step, and that message
     carries the join of that step's derivations. Bud's channel `pending` buffer already does this.
  3. **Merge at the receiver** applies only within a delivered batch. Accumulating values across ticks takes an
     explicit persistent sink.
  4. **Divergence inside a tick has no meaning.** It is a hard error; Ross–Sagiv's transfinite limits are rejected.
  5. **Verification uses FLP/Ferraris (clingo) aggregate semantics, never Gelfond–Zhang.** Our least-fixpoint semantics
     agrees with FLP (checked on clingo) and disagrees with GZ (GZ Ex. 8).
- **Carry-over (§4).**
  - *TPLP Thm 4:* conjectured to hold for Dedalus^L under six side conditions C1–C6. The key new one is **local
    convergence**: every per-tick stratum fixpoint must be reached in finitely many Kleene steps. Examples T7-neg and
    T10b show the correspondence breaking without it.
  - *Dedalus+ confluence:* carries over under "semipositive^L" plus a refined **guarded asynchrony^L**. I give a proof
    sketch: in every fair run, each cell's value converges to the join of the Kleene chain of the flattened program.
    Across ticks the argument needs **no** ACC or continuity; inside a tick it needs local convergence. The refinement
    (§4.3) is that an ephemeral async relation counts as guarded only if it is consumed by **join-morphisms** into
    persistent state. Test T3 shows that a non-join-prime threshold applied to an ephemeral lattice batch is diffluent.
- **Provenance (§6).**
  - A lattice cell is annotated with an element of the semimodule PosBool(X) ⊗ 𝓛 ([ADT] §2.3): a finite antichain of
    guarded values (φᵢ, vᵢ).
  - Morphisms map over the pairs and bimorphisms are bilinear.
  - A monotone threshold becomes a PosBool formula whose minimal models are its **minimal supports**.
  - For distributive lattices with finite decompositions I show [ours] that the support of `x ⊒ t` is a CNF over the
    atoms of `t`: ⋀_{a∈⇓t} ⋁_{i: a⊑vᵢ} φᵢ. Its falsifiers are therefore "for some atom a, lose every contributor of a".
  - Cardinality thresholds (`size ≥ k`) become an at-most-(k−1) constraint over per-element survival variables. This
    refines TEST-024: the k-of-n count is over **elements**, not over messages.
  - LDFI stays complete as long as every claimed support is **genuine** (sufficient). It need not be minimal.
- **Test corpus (§7).** Thirteen programs, T1–T13, each with exact values validated by simulator or clingo. They
  include a quorum vote over `lset` (10 minimal falsifiers of size 3), a max over a lossy channel, a lattice sent
  over `@async` with merge at the receiver, merge at the sender, ⊥-normalization, antitone reads across strata, a
  divergence hard error, an ultimate value that diverges, a lattice "marriage ceremony", vector clocks, an LWW `Lex`
  register, company control (checked against clingo) and key presence in a replicated `lmap`.

## 2. What the prior art actually provides (precise extracts)

### 2.1 TPLP: the base we extend
- **Instances are sets of facts** over a schema ([TPLP] §3.1). A Datalog¬ rule is a triple (head, pos, neg), and
  safety requires every variable to occur in `pos` (§3.2).
- **Stable models** (§3.2.3, p. 8). `ground_M(P, I)` removes every ground rule whose `neg` meets M and strips the
  remaining negative atoms. M is stable iff M is the output of `ground_M(P, I)` on I.
- **Dedalus programs** (Def. 4.1, p. 10) are safe, and their deductive rules are syntactically stratifiable. The paper
  also assumes every rule has at least one positive body atom (§4.3.1, footnote 7).
- **Async rules become dynamic choice** (§4.3.1, rules (3)–(6), p. 16). "If multiple asynchronous rules in P have the
  same head predicate R, only new cand_R-rules have to be added because the rules (4)–(6) are general for all
  R-messages". This is **set sending semantics**: one arrival time per (sender, step, addressee, fact).
- **Local transition** (§5.1.3, pp. 25–26):
  - `I = st_a(x) ∪ untag(m)`
  - `D = deduc_P(I)` (stratified semantics)
  - `δ_{i→y}` is built from `async_P(D)`
  - `st_b(x) = H(x) ∪ induc_P(D)`
  - Remark 2: sequential transitions simulate parallel ones.
- **Theorem 4** (p. 23): the traces of fair runs are exactly the restrictions of the models of `pure(P)` to
  `sch(P)^LT`.
- **§6** (p. 38) lists aggregation and non-determinism as future work: "we expect that this work can be extended to
  languages that incorporate more powerful language constructs such as the ones mentioned above".

### 2.2 Ross & Sagiv: lattice-ordered interpretations for aggregation
- **Cost predicates** (Def. 2.3). A cost predicate has a distinguished cost argument that is **functionally dependent**
  on the other arguments. The motivation is that bag-counting derivations is meaningless under duplicate elimination
  (pp. 3–4). The aggregate subgoal `C = F E : p(X̄, Ȳ, E)` groups by X̄ (Def. 2.4). The `=r` variant is false on an
  empty group.
- **Default values** (§2.3.2, pp. 5–6). A `declare default t(W,0)` predicate gives every non-cost instance the default
  cost, and "we shall insist that the default truth value is the minimal element with respect to the cost order".
  **This is the literature's ⊥-normalization.**
- **Cost-consistency** (Def. 2.6, p. 8): one application of the rules must never produce two atoms that differ only
  in their cost. **Conflict-freedom** (Def. 2.10, p. 10) is a sufficient syntactic check: every rule is cost-respecting
  under Armstrong's axioms, and any two unifiable heads either admit a containment mapping or trigger an integrity
  constraint. *Ross–Sagiv treat a conflict as an error. Bloom^L merges instead.* See §3.3.
- **Interpretations** (Def. 3.3, p. 12) respect the functional dependency. I ⊑ I′ iff every atom of I has a pointwise
  ⊑-greater atom in I′. If the cost domains are complete lattices, the interpretations form a complete lattice
  (Thm 3.1).
- **The consequence operator** (Def. 3.7, p. 14) is `T_P(J, I) = {heads of satisfied ground rules} ⊔ J_∅`. P is
  *monotonic* if T_P is ⊑-monotone in J (Def. 3.8), and then its least fixpoint is the least model (Prop. 3.3,
  Cor. 3.5).
- **Sufficient syntactic condition** (Def. 4.5 and Lemma 4.1, p. 18): rules are well-formed, every CDB aggregate is
  monotone (or pseudo-monotone over default-valued predicates), and the built-ins are monotone.
- **Kemp–Stuckey stable models** eliminate aggregates in the reduct and admit two incomparable stable models of
  shortest-path (§5.3, §5.5, p. 24). Ross–Sagiv propose instead to "apply the reduction (with respect to M) to
  negative literals only, and not to aggregate literals. … If the reduced program is monotonic, and if M is its unique
  minimal model, then call M 'stable.'" **§3.6 adopts this definition.**
- **Limits** (Ex. 5.1, p. 25; §6.2). The `halfsum` example reaches `p(a,1)` only in the limit. "T_P may be monotonic
  in its first argument without being continuous, and so iteration … beyond ω may be required". We reject this in D8.
- **Iterated minimal models** (§6.3): strata are evaluated bottom-up, and Prop. 6.1 relates this construction to
  well-founded models.

### 2.3 Flix: cells and compactness
- **Cells** ([FLIX] §3.2). The Herbrand base is partitioned into *cells*: the same predicate and the same first n−1
  terms. Each cell carries a complete lattice.
- **Truth is downward-closed:** "a ground atom A is true w.r.t. an interpretation I if ∃A′ ∈ I such that A ⊑_S A′".
- **Minimal models must be compact:** one element per cell.
- **Naive evaluation** "we must compute the least upper bound in every cell of the interpretation before we apply T_p
  again". The paper insists "that the Flix lattices be of finite height".
- **Functions** (§3.3). Monotone filter functions map lattice elements to bool with false < true. Transfer functions
  must be *strict and monotone* ("when a function is applied to ⊥ it returns ⊥"), and non-filter functions may appear
  only in the head's last term.
- **No negation** (§3.5).
- **Semi-naive Δ** (§3.7): ΔPᵢ holds the cells whose value *strictly* increased, and those cells carry the joined
  value. The A(Odd) ⊔ A(Even) = A(⊤) example shows that rules see joined cell values.

### 2.4 Datalog°: convergence
- **Least fixpoint semantics** over a POPS. The naive algorithm can diverge, and the paper considers only finite
  convergence: "we do not consider 'convergence in the limit'" (§1).
- **Theorem 1.2** (p. 5): every datalog° program converges iff the semiring P⊕⊥ is stable. It converges in a number
  of steps depending only on |ADom| iff P⊕⊥ is p-stable. A 0-stable semiring gives at most N steps.
- **ACC is sufficient but not necessary.** Trop+ is 0-stable but has no ACC (pp. 5, 15).
- **Semi-naive** (Def. 6.2, Alg. 3, Thm 6.4, pp. 38–39) is correct over complete distributive dioids, using
  b ⊖ a = ⊓{c | a ⊕ c ⊒ b}.
- **Negation** can be added under Fitting's 3-valued semantics (§7). Well-founded and stable semantics are left open
  (§9).

### 2.5 Datafun (ICFP'16, POPL'20)
- **Monotonicity is a type** ([DF16] §2). There are discrete and monotone variables, and a discrete elimination
  "wipes clean" the monotone context (§4.2).
- **Boolean elimination has two rules** (§4.3). `IF+` is monotone only when the else-branch is ε, the least value;
  this is the typing reason `when_true` is monotone. `IF` requires a constant subject.
- **`fix`** requires a finite semilattice eqtype. The bounded `fix x ≤ e⊤ is e` *clamps* to the bound (§3.4.1). We do
  **not** adopt clamping; it would silently truncate, which SEM-032 forbids.
- **Change structures** ([DF20] §4.2–4.3, Lemma 4.1). At every semilattice type, ΔL = L and dx changes x into y iff
  x ∨ dx = y. A derivative f′ takes a base point and a change, and `semifix(f, f′) = fix f`. This justifies
  incrementalizing non-morphism monotone functions (such as `size`) with a base-point derivative, not only morphisms.

### 2.6 Conway's dissertation, Flo
- **[THESIS-NC] §3.2 (p. 24):** there is no formal semantics.
- **[THESIS-NC] §3.7 (pp. 37–38):** values that are "monotonic-then-immutable" (`lcart`, `lbool`) let any function be
  applied once the value is immutable. This is the informal root of sealing lattice cells (§4.4).
- **[FLO] Def. 3.1 (eager execution, p. 9):** processing part of the input and then Δ reaches the same stuck state as
  processing the whole input.
- **[FLO] Def. 3.3 (streaming progress, p. 10):** an operator may block only on bounded inputs.
- **[FLO] §6.2 (pp. 23–24):**
  - `to_sequence` on an unfixed LVar violates eager execution.
  - Waiting for `fixed` violates streaming progress on unbounded input.
  - `thresh(t₁…)` is the safe read. Its typing side condition is garbled in the PDF text; I read it as the LVars
    pairwise-incompatibility condition, as R04 §13 did.

### 2.7 Answer-set semantics of aggregates (needed for VER-003)
- **FLP reduct** ([FLP] Def. 2.5): Pᴵ keeps exactly the rules whose whole body, aggregates included, is true in I.
- **FLP answer set** (Def. 2.6): I is an answer set iff it is a subset-minimal model of Pᴵ. Aggregates are
  "monoliths".
- **Properties:** answer sets are minimal models (Thm 3.3). **If all literals are monotone, the answer sets are
  exactly the minimal models** (Thm 3.5). On aggregate-free programs FLP coincides with Gelfond–Lifschitz (Thm 3.6).
- **Ferraris' semantics coincides with FLP** on programs whose aggregates are not preceded by `not` ([FLP] §5, citing
  Ferraris Thm 3). clingo implements the Ferraris-style semantics of Abstract Gringo ([AG] §4.7).
- **Monotone count and sum:** `count`, `sum+` and `max` compared from below (`k <= #count{…}`) are monotone, and the
  translation's antecedent can then be dropped ([AG] §5.1).
- **Gelfond–Zhang (Alog)** replaces a true aggregate by the *entire* set it ranges over ([GZ] Def. 1, clause 5). This
  is the vicious-circle principle. Consequences:
  - `p(a). p(b) :- card{X:p(X)} > 0.` has **no** answer set in Alog (Ex. 8).
  - The same program has answer set {p(a), p(b)} under FLP. **I confirmed this on clingo 5.8.2.**
  - `p(a) :- #count{X:p(X)} = 1.` has only the empty answer set on clingo, as it does under FLP.

### 2.8 PreM: extrema inside recursion
- **Definition** ([PREM] Def. 1): γ is PreM to T iff γ(T(I)) = γ(T(γ(I))).
- **Thm 1:** if T_γ reaches a fixpoint in n steps, then γ(T^↑ω(∅)) = T_γ^↑n(∅).
- **Thm 2:** that fixpoint is a minimal fixpoint of T_γ.
- **Prop. 1:** min is PreM to deflation-preserving cost procedures, and max to inflation-preserving ones.
- **Reading for us [ours].** An `lmin`/`lmax` cell is exactly the γ = is_min/is_max "compaction" of the underlying set
  of derived costs. By Thm 1, lattice semantics therefore agrees with "stratified set semantics followed by min"
  whenever the set program converges. When the set program diverges (cycles), the lattice program still converges;
  that is the PreM optimization. This gives VER-003 a stratified alternative encoding of `lmin`/`lmax` (§5.1).

### 2.9 Provenance for aggregates
- **Semimodules** ([ADT] §2.2). Aggregates are semimodules over the annotation semiring. "A commutative monoid M is a
  B-semimodule if and only if its operation is idempotent", so every lattice join is a B-semimodule.
- **Tensor product** (§2.3): K ⊗ M consists of bags of simple tensors k⊗m, modulo (k+k′)⊗m ∼ k⊗m + k′⊗m and
  k⊗(m+m′) ∼ k⊗m + k⊗m′.
- **Prop. 3.2:** no K-relation semantics for MAX/MIN is both set-compatible and commutes with homomorphisms. That is
  why values have to be tensors and cannot be plain annotations.
- **Thm 3.12:** an idempotent M is *compatible* (ι injective) with every +-positive semiring K. This includes
  PosBool(X), Why(X) and N[X].
- **Comparison tokens** (§4.2). Comparing aggregate values uses symbolic tokens `[c₁ = c₂]` that are resolved once
  the annotations are valued. Prop. 4.2: without them, nested aggregation has no semantics that is both
  set-compatible and commutes with homomorphisms.

### 2.10 What Bud does (ground truth for message semantics)
- **`merge_to_buf`** (`collections.rb`):
  - An identical tuple is ignored.
  - A differing non-lattice non-key column raises `KeyConstraintError`.
  - Otherwise every differing lattice column becomes `old.merge(new)`, and the stored tuple is replaced only if some
    lattice value changed.
- **Sends:** `<~` calls `pending_merge`, which calls `do_insert(t, @pending)`. The send buffer is therefore
  **key-normalized with lattice merge** within a tick. `BudChannel#flush` then sends one datagram per pending tuple.
- **Receives:** `receive_inbound` inserts each arriving tuple with `tables[tbl_name] << b`, that is,
  `do_insert(…, @storage)`. The same-tick arrival batch is therefore key-normalized with lattice merge as well.
- **Channels are scratch on the receive side:** `BudChannel#tick` does `@storage.clear`. This matches R03 §2 and
  R04 §3.6.

## 3. Dedalus^L: candidate normative definition [ours, built from §2]

Notation follows TPLP. **Bold numbered items D1–D13 are proposed as normative.** Examples use a neutral rule notation:
- `R(k̄; e)` is a head or generator atom whose lattice value is `e`.
- `x = R[k̄]` is a lookup.
- `¬R(k̄)` is negation.
- `@next` and `@async` are the temporal annotations.
- Declarations are written `rel R(k̄)` (a set relation), `lat R(k̄) : 𝓛` (a persistent lattice relation),
  `scratch lat …` (a tick-scoped one) and `chan R(@dst, k̄) [: 𝓛]` (an ephemeral async relation).

### 3.1 Lattices, schemas, instances

**D1 (Lattice type).** A lattice type is a bounded join-semilattice 𝓛 = (L, ⊔, ⊥) with its derived order
a ⊑ b ⟺ a ⊔ b = b ([SOCC] §3.1; laws L1–L10 of R04 §2.1). It has an optional ⊤ and a **canonical-form** function
`can: L → L` used for equality, hashing and message identity. For `lmap`, `can` drops ⊥-valued entries; for `lset`
it is the identity.

**D2 (Lattice-valued schema).** Every relation R has
- key columns k̄_R, whose types are not lattices, and
- exactly one value lattice 𝓛_R. Several lattice columns are treated as their product (R04 §10.1(2)).

A **set relation** is the case 𝓛_R = 𝔹 = ({ff, tt}, ∨, ff). A relation with no key columns and a non-𝔹 lattice is
a Bloom^L **lattice identifier**. Each relation also has a persistence class: *persistent* (the default for lattice
relations, CR-24) or *tick-scoped* (the default for set relations other than `table`, SEM-008). The location is the
first key column in the IR (CR-14).

**D3 (L-instance, ⊥-normal form).** A *cell* is c = (R, ā). An L-instance I maps every cell to I(c) ∈ 𝓛_R, and its
support supp(I) = {c | I(c) ≠ ⊥} must be finite. I is written in ⊥-normal form as the finite set {c ↦ I(c) | c ∈ supp(I)}.
- Order and join are pointwise: I ⊑ J iff ∀c. I(c) ⊑ J(c), and (I ⊔ J)(c) = I(c) ⊔ J(c).
- On set-only schemas, ⊑ is ⊆ and ⊔ is ∪, so D3 is exactly TPLP's §3.1 instance.
- This is Ross–Sagiv's functional dependency (Def. 3.3) together with Flix's compactness (§3.2).

**⊥-normalization rules (normative) [ours, from RS §2.3.2, R04 §10.1(6), SEM-034]:**
- **N1.** A cell whose value is ⊥ does not exist. `R(ā; ⊥)` means that no fact exists.
- **N2.** Values are compared, hashed and used as message identity only in canonical form. `lmap` entries mapped to ⊥
  are removed recursively.
- **N3.** A derivation whose value is ⊥ is a no-op, because ⊥ is the identity of ⊔. This holds for heads, for `<+`
  and for `@async`: a ⊥-valued async derivation creates **no message**, no clock or lineage leaf, and no receiver
  wake-up (SEM-009).
- **N4.** A generator atom `R(t̄; x)` ranges over supp(I) only.
- **N5.** A lookup `x = R[t̄]` (t̄ bound elsewhere) returns I(R, t̄), which may be ⊥. A 0-ary lattice relation is read
  **only** by lookup, which matches the Bloom^L identifier, "initially bound to ⊥" ([SOCC] §3.2.1).
- **N6.** Cell presence (`key?`, `R(t̄; _)`) is the monotone threshold "value ≠ ⊥".

**Consequence [ours]: morphisms need not be strict** (this confirms CR-23). Under N4, a generator never binds ⊥. Under
N5, applying a non-strict f (for example `lset.size`, where size(∅) = 0) through a lookup yields f(⊥), and that
result is monotone in the looked-up cell. Flix's strictness requirement ([FLIX] §3.3) exists only because Flix does
not separate absence from ⊥; N1–N5 make that separation. **Test T5** pins this down.

**Numeric ⊥.** T5 shows that `lmax<int>` must have an adjoined ⊥ = −∞, which is Bud's choice (R04 §3.4), so that
`cnt = 0` is a real value and not "absent". Hydro's `Max<u64>` uses `Default` = 0 as ⊥ (R04 §2.4), and that would make
`cnt(; 0)` vanish. The choice is user-visible; see the proposed ODD.

### 3.2 Rules, polarity and positions

**D4 (Expressions and polarity).** Lattice expressions are built from variables, constants and operations. Each
operation declares a class per argument: M, BM, Mon, Anti or NM (LANG-125; R04 §2.4 is normative). A *threshold* is a
monotone map into 𝔹 ([FLIX] §3.3 "monotone filter functions"; [FLO] §6.2). For every occurrence of a lattice variable
x in a rule, take the composite polarity along each path from x to the rule's head value or to a guard:
- The occurrence is **monotone** if every such path has an even number of Anti edges and no NM edge (ANA-021, R04 §2.2).
- Otherwise it is **exact**.

`reveal`, `==` or `<` on raw lattice values, non-lattice aggregates (LANG-101) and `¬R` are all exact.

**D5 (Rules).** The three rule kinds (deductive, `•`/`@next`, `| y`/`@async`) are TPLP's (§4.1.1). The body literals
are:
- positive **generator** atoms `R(t̄; x)`;
- **lookups** `x = R[t̄]`;
- **negations** `¬R(t̄)`, which read as `R[t̄] = ⊥` and are exact;
- built-in guards and assignments;
- threshold guards.

The head is `R(t̄; e)`. **Safety (range restriction):** every key variable of the head, of a lookup and of a negation
occurs in some positive generator atom. This is TPLP's safety plus Ross–Sagiv's "limited variables" (Def. 2.5). Every
rule has at least one generator atom or a lookup of a 0-ary relation; this generalizes TPLP §4.3.1 footnote 7.

**D6 (Immediate consequence T^L).** A valuation V for rule φ on instance I maps key variables to dom. It binds the
lattice variable of each generator atom `R(t̄; x)` to **exactly** I(R, V(t̄)), and requires that cell to be in supp(I);
lookups are bound the same way.
- V *satisfies* φ if every guard evaluates to tt and every negated cell is ⊥.
- A satisfying V contributes the singleton instance {(R_h, V(t̄_h)) ↦ ⟦e⟧_V}.
- **T_φ(I)** is the ⊔ of all these contributions.
- **T_P(I) = I ⊔ ⨆_φ T_φ(I).**

This follows Flix's "compute the least upper bound in every cell … before we apply T_p again" ([FLIX] §3.2) and Ross–Sagiv's
Def. 3.7. For monotone occurrences, binding to the exact cell value gives the same models as Flix's downward-closed
truth, since the largest binding yields the largest head [ours]. Ross–Sagiv define heads with the same key and
different costs as an error. **Here they merge.** In Ross–Sagiv terms, every lattice relation R is an implicit
aggregate: R(k̄, C) ← C = ⊔E : R′(k̄, E), where ⊔ over a multiset is a monotone aggregate (their Fig. 1 rows `max` and
`union`). Cost-consistency is therefore automatic [ours].

**Key conflicts.** A set relation may declare a key with non-lattice payload columns. If T_P(I) contains two different
payloads for one key, that is a key-constraint error (SEM-050). The transition is then undefined, and the engine
raises a hard error. Ross–Sagiv's conflict-freedom check (Def. 2.10) is the corresponding static analysis, proposed
in FEATURES.md as ANA-140.

**D7 (L-stratification).** Build the dependency graph with an edge R → H for each rule headed by H that reads R. Label
the edge **+** if every occurrence of R's value is monotone and **−** otherwise; negation is always −. A stratification
σ satisfies σ(R) ≤ σ(H) for + edges and σ(R) < σ(H) for − edges, as in TPLP §3.2.2. P is L-stratifiable if its
*deductive* rules admit such a σ. Inductive and asynchronous rules read the completed deductive fixpoint, so they
never need stratifying (TPLP §5.1.2; SEM-003). Within one stratum, T_{Pᵢ} is ⊑-monotone on the instances that agree
on lower strata. This is the analogue of [RS] Lemma 4.1 [ours].

**D8 (Stratum evaluation and convergence).** Pᵢ(I) = T_{Pᵢ}ⁿ(I) for the least n with T_{Pᵢ}ⁿ⁺¹(I) = T_{Pᵢ}ⁿ(I).
If no such n exists, **Pᵢ(I) is undefined.** When defined, it is the least fixpoint of T_{Pᵢ} above I (Kleene;
[DLO] Def. 3.1 remark), and deduc_P(I) = P_k(…P₁(I)…).
- **Rejected alternatives:** Ross–Sagiv's transfinite least model (§6.2, Ex. 5.1) and Datafun's clamped bounded fix
  (§3.4.1). Undefinedness is a **hard runtime error** (SEM-032, ENG-047).
- **Sufficient static guarantees** for definedness:
  - ACC on every lattice written in a recursive stratum ([FLIX]; [DF16] §2);
  - p-stability of the underlying semiring for semiring-shaped recursion ([DLO] Thm 1.2, e.g. Trop+ for `lmin` with
    non-negative `+`);
  - PreM-style inflation or deflation preservation for `lmin`/`lmax` ([PREM] Prop. 1).

### 3.3 Subprograms, transitions, delivery

**D9 (Subprograms).**
- **induc_P(D)** is the one-step ⊔ of every inductive rule applied to D. It includes the **implicit identity rule**
  `R(k̄; x)• ← R(k̄; x)` for every *persistent* lattice relation (CR-24). Set relations persist only through explicit
  rules, as in TPLP and SEM-008.
- A **tick-scoped** lattice has no implicit persistence, so its value at t+1 is exactly the join of the `<+`
  contributions staged at t. Deletion (`<-`) and upsert (`<+-`) are *not* defined on lattice relations, because both
  are non-monotone replacements (LANG-122). A monotone "reset" is written with a `Lex<epoch, 𝓛>` lattice (LANG-131):
  bumping the epoch makes the old component irrelevant under the Lex merge.
- **async_P(D)** is the one-step ⊔ of every async rule, with the addressee as the first key. The result is an
  L-instance, so it has **exactly one cell per (addressee, relation, key) per step, carrying the join of every
  derivation of that step.** This is **merge at the sender**, the lattice generalization of TPLP's set sending
  semantics. Bud's `pending` buffer does the same (§2.10).

**D10 (Configurations and transitions).** These are TPLP §5.1.1 and §5.1.3 with ∪ replaced by ⊔:
- st(x) is an L-instance. bf(x) holds pairs (i, (R, ā; v)) with v = can(v) ≠ ⊥.
- A transition (ρa, x, m, i, ρb) with m ⊆ bf_a(x) computes:
  ```
  I       = st_a(x) ⊔ ⨆_{(j,f) ∈ m} {f}        -- delivered batch joined cellwise ("merge at the receiver")
  D       = deduc_P(I)                          -- must be defined (D8); otherwise the transition does not exist
  δ_{i→y} = { (i, (R, ā; v)) | ((R, y, ā) ↦ v) ∈ async_P(D) }
  st_b(x) = H(x) ⊔ induc_P(D)
  bf_b(x) = (bf_a(x) ∖ m) ∪ δ_{i→x};   bf_b(y) = bf_a(y) ∪ δ_{i→y}  (y ≠ x)
  ```

**Delivery semantics (resolving the SEM-007 question).**
- The delivered batch at one step is the **⊔-normalization** of every message that arrives at that step. For
  𝓛 = 𝔹 this is exactly SEM-007's per-tick set.
- **Message identity** is (sender, send step, addressee, relation, key), and the message carries the join formed at the
  sender. For set relations whose key is the whole tuple, this is SEM-007's "(sender, send tick, receiver, fact)".
- Two messages with the same key that arrive at the same step merge. Messages that arrive at different steps stay
  separate, because channels are ephemeral. **Accumulation across ticks requires a persistent sink** (`store <= chn`);
  LANG-137 is to be read this way.
- Idempotence makes duplicates and at-least-once delivery harmless for every *monotone* consumer. An ephemeral
  consumer that is *not* a join-morphism sees how the arrivals were batched; T3 shows this.

**Engine consequence [ours].** Shipping deltas instead of full values (Hydro, R04 §10.4) is observable to ephemeral
non-morphism readers. The optimization is therefore legal only for channel relations whose every consumer is a
join-morphism into persistent state. This refines ODD-05(c).

### 3.4 Output and ultimate L-models

**D11 (Ultimate L-model) [ours; it reduces to MAR §2.2 on sets].** Take a run and an output cell c, and let h_c(s) be
c's value in D at step s of its node. Define
`ult(c) = { v ∈ 𝓛 | ∃t ∀s ≥ t. h_c(s) ⊒ v }`,
the ideal of *eventually-always* lower bounds. It is an ideal: it is down-closed, and if v₁ and v₂ are both eventually
below h then so is v₁ ⊔ v₂. So ult(c) is an element of the ideal completion Idl(𝓛).
- If h_c is eventually constant at v, then ult(c) = ↓v, a compact value.
- If h_c increases forever, ult(c) is the directed union of the chain, a non-compact limit ("diverges"). T8 is an
  example.
- For 𝔹, ult(c) = tt iff the fact is eventually always true, which is exactly MAR's ^T.

An *ultimate threshold fact* θ(c) for a monotone threshold θ is one that is eventually always true. The **ultimate
L-model** of a run maps each output cell to ult(c). The program is **confluent** if every fair run (equivalently,
by Thm 4^L, every model) has the same ultimate L-model (SEM-044).

### 3.5 Declarative semantics: `pure^L(P)` and L-stable models

**D12 (`pure^L(P)`).** Apply TPLP §4.3–4.5 with these changes:
- Rules (1) and (2) keep their lattice head expressions. Location and time are key columns.
- Each persistent lattice relation gets its implicit persistence rule `R(x,t,k̄; v) ← R(x,s,k̄; v), tsucc(s,t)`.
- **Async (3)–(6) become:**
  ```
  snd_R(x,s,y,k̄; e)       ← B{…}⇑x,s                                  -- a lattice relation: merge at the sender
  sent_R(x,s,y,k̄)         ← snd_R(x,s,y,k̄; _)                          -- generator: non-⊥ only (N3, N4)
  cand_R(x,s,y,t,k̄)       ← sent_R(x,s,y,k̄), all(y), time(t), ¬before(y,t,x,s)    -- rule (9)
  chosen_R / other_R      -- rules (4), (5) over the key tuple k̄, unchanged
  R(y,t,k̄; v)             ← chosen_R(x,s,y,t,k̄), snd_R(x,s,y,k̄; v)     -- (6^L): arrival merges into R
  ```
- `before` (7), (8), (10) and the finiteness rules (11)–(14) are unchanged, because they are set relations.

**D13 (L-stable model) [ours; from RS §5.5].** Let M be a candidate L-interpretation and G the ground program (key
variables over adom ∪ ℕ). **The reduct G_M:**
- remove every ground rule that has an *exact* literal false in M;
- in the remaining rules, replace every exact read by its value in M.

G_M is a monotone L-program. **M is L-stable iff M is the ⊑-least model of G_M on decl(H), and every cell value in M
is finite.** That last condition rejects the completion values that D8 excludes. A *model* of P on H is an L-stable
model of `pure^L(P)` on decl(H) (the analogue of TPLP Def. 4.4).
- On set-only programs, D13 is Gelfond–Lifschitz, exactly as TPLP §3.2.3 uses it.
- On programs whose literals are all monotone, D13 gives the unique least model. That coincides with the FLP answer
  set: by [FLP] Thm 3.5 the answer sets of a program with only monotone literals are its minimal models, and a
  non-disjunctive program with monotone bodies has models closed under intersection, hence a unique minimal model
  [ours].
- D13 is **not** Gelfond–Zhang: GZ Ex. 8 has a model here and none in Alog.

### 3.6 Worked micro-example (QuorumVoteL, SoCC Fig. 3, in Dedalus^L)
```
chan vote(@c: node, v: node)          lat votes() : lset<node>          rel decided()
vote(@C, V)@async :- cast(), coord(C), Id(V).
votes(; {V})      :- vote(V).                     -- generator over the delivered batch; head merges
```

- Edges: vote → votes (+), votes → decided (+). One stratum; semipositive^L.
- At the coordinator, a step whose batch holds votes {v1,v2} computes I = {votes ↦ S ⊔ {v1,v2}}, and D adds `decided`

- induc_P carries `votes` (implicit persistence) and `decided` (explicit rule).

### 4.1 Theorem 4^L (operational = declarative)

**Claim (conjecture, not proven).** Let P be a Dedalus^L program satisfying C1–C6 below. For every input H, the
traces of fair runs of P are exactly the restrictions to sch(P)^LT of the L-stable models of `pure^L(P)` on decl(H).

| # | Side condition | Why it is needed (evidence) |
|---|---|---|
| C1 | L-stratification of the deductive rules (D7) | This is TPLP Def. 4.1 lifted. Exact reads inside recursion give the FLP/GZ multiple-model ambiguities ([GZ] Ex. 2/7; [RS] §5.5) |
| C2 | **Local convergence:** deduc_P is defined at every step of every fair run (D8) | Without it a run gets stuck while the completion's least fixpoint contains ±∞, so runs and models differ. See T7-neg, T10b and [RS] Ex. 5.1 (halfsum reaches its value only at ω) |

**Proof sketch [ours].** TPLP §5.2–5.3 builds M from a run and a run from M. It manipulates only the set relations
`before`, `cand`, `chosen`, `other` and the finiteness relations, and these are untouched in `pure^L`. The one new
obligation is that for each (x, s), M restricted to (x, s) equals deduc_P(st ⊔ delivered). Induct over the
well-founded order ≺_M (TPLP Claim 5, §5.3.1) and over the strata, using this lemma: *for an L-stratified program the
iterated least fixpoint is its unique L-stable model.* That lemma is the analogue of "stratified ⇒ unique stable
model = perfect model" and of [RS] §6.3 / Prop. 6.1. Under C2 every fixpoint involved is finite, so the "all values
finite" clause of D13 holds. **Status:** a paper proof is needed in the design phase. Mechanizing it is VER-019. As a
cheap guard, the design should test differentially: bounded ASP enumeration of models (§5.1) against exhaustive
schedule enumeration in the simulator. I did this for T9 (§7).

**Stratification independence** (SEM-023 carry-over) [ours]: each stratum's result is the least fixpoint above its
input, so the standard argument goes through unchanged.

### 4.2 Dedalus+^L and confluence (ANA-025)

**Definitions [ours, refining MAR §3.2 and ANA-024].**
- **semipositive^L:** every exact occurrence (negation, Anti, NM, `reveal`, non-lattice aggregate) reads only EDB
  relations.
- **guarded asynchrony^L:** every async head relation p is either
  - (a) persistent (an explicit persistence rule for set relations; the persistent class for lattices), or
  - (b) ephemeral but consumed only by rules that meet all four of these conditions:
    1. p is their only non-EDB positive atom;
    2. they are **join-morphisms in p's value**;
    3. they contain no exact occurrence of p;
    4. they head a persistent relation, or a relation that is itself guarded in the sense of (b).

  For a set relation, condition 2 holds automatically, because every single-atom rule preserves ∪. For a lattice it
  **fails for thresholds that are not join-prime**. T3's `seen_both_eph` tests the two-atom threshold {x↦3, y↦5} on
  the ephemeral batch, and it is diffluent even though it is "just one monotone rule".

**Theorem 1^L (confluence) [ours, proof sketch].** A Dedalus+^L program satisfying C2 is confluent. For every cell,
ult(c) = ⨆ₙ Kₙ(c) in Idl(𝓛), where Kₙ is the Kleene chain of the *flattened* program A(P): every async rule becomes an
inductive rule, as in MAR Cor. 1.
- *(≤)* Every state in every fair run is ⊑ Kₙ for some finite n. Induct on transitions: each transition applies
  finitely many monotone rule applications to inputs that are ⊑ some K_m. C2 makes the in-tick part finite.
- *(≥)* Each Kₙ is eventually ⊑ the run's state, by induction on n. Kₙ depends on finitely many derivations. All
  their inputs persist, which is what semipositive^L and guarded asynchrony^L guarantee. Every node is active
  infinitely often and every message is eventually delivered (fairness, TPLP §5.1.4). So each derivation eventually
  fires, and its contribution stays.
- Hence all fair runs have the same limit. A threshold on a compact element t is ultimately true iff t ⊑ some Kₙ.

**No ACC and no Scott-continuity is needed across ticks:** the argument compares against the Kleene chain, not
against a fixpoint. **This is the lattice analogue of MAR Lemma 3** (temporal inflation) plus Theorem 1.

**What falls outside the class.**
- *Exact reads of async-fed cells* (T9 `exactly_one`) are diffluent.
- *Exact reads of eventually-constant cells* can still be confluent while falling outside the class. T11's
  `val_is_y` is re-derived every tick from a register that is eventually constant. This mirrors BENCH-084, a program
  that is confluent but not certified. The certificate must say "not certified", not "diffluent".

### 4.3 Dedalus_S^L (ANA-026), sealing, CRON

- **Sealing [ours].** In Dedalus_S^L, an exact read of an async-dependent lattice cell is allowed iff it is guarded by
  the seal `p_done` of that cell (the MAR §4.2 rewrite; ack counting in MAR App. D works per message, that is, per
  key). A sealed cell is Conway's "monotonic-then-immutable" value ([THESIS-NC] §3.7) and Flo's *fixed* stream
  ([FLO] §6.2). This also gives `reveal` and `to_collection` their only confluent use on unbounded inputs, which
  matches ANA-031.
- **CRON (Thm 6.1: positive, consistent ⇒ tolerates non-causality)** [conjecture, ours]: this should extend to
  programs with *no* exact occurrences at all, because every operation is monotone and replaying a lattice message is
  idempotent. If it holds, crash recovery may bulk-load logs of lattice messages (SEM-043 non-causal replay). It must
  be proven before SEM-043 relies on it for lattices.
- **Consistency vs. confluence (CR-29):** unchanged. Ameloot's "message join" program has lattice analogues, such as
  T3 with `seen_both_eph`.

## 5. Encodings for verification

### 5.1 ASP / clingo (VER-003)

**Semantics to target.** clingo implements the Ferraris-style semantics of Abstract Gringo ([AG] §4.7). On aggregates
that are not under `not`, that semantics coincides with FLP ([FLP] §5). Our D13 agrees with FLP on the monotone
fragment (§3.5). Exact reads are stratified by D7, so the Ferraris/FLP difference for negated aggregates never
arises. **Do not use Alog/GZ.** On `p(a). p(b) :- #count{X:p(X)} > 0.`, Alog has no answer set, while clingo and
Dedalus^L both give {p(a), p(b)}; I ran this on clingo 5.8.2.

**General scheme.** Every relation atom gets its location and time as the first arguments, as TPLP's ⇑x,s does.
Cells are encoded in one of three ways.
- **(E-atoms)** Down-set of join-irreducibles. This works for distributive lattices with finite decompositions
  (Birkhoff; Enes et al. Prop. 1–2 via R04 §5.5). A cell becomes the set of irreducible atoms below its value, so ⊔
  becomes ∪ and every morphism becomes plain rules. The size is O(height) per cell for chains.
- **(E-contrib)** Works for any lattice. A cell becomes the set of values contributed to it. Reads are aggregates
  (`#max`, `#min`, `#count`), morphisms are applied per contribution, and exact reads use an aggregate in a higher
  stratum. The risk is infinitely many contributions on cycles. Prune them with PreM (`is_min` pushed into the
  recursion, [PREM]) or bound the values.
- **⊥ is the absence of atoms.** clingo's `#max{}` over an empty set is `#inf`, which matches ⊥ = −∞ for `lmax`.

**Per-lattice encodings** (checked: T1, T2, T9, T10, T11, T13 and T12 run end to end on clingo 5.8.2 and reproduce
the §7 values):

| Lattice | Encoding | Monotone reads | Exact reads (higher stratum) |
|---|---|---|---|
| `lbool` | atom `b(N,T,k̄)` | `when_true`: body atom | `not b(…)` |
| `lmax<int>` on [lo, hi] | E-atoms: `ge(N,R,T,k̄,V)` plus closure `ge(…,V-1) :- ge(…,V), V > lo.` | `x >= c` ⇒ `ge(…,c)`. Morphism `+c`: `ge(…,V+c) :- ge(…,V)`. Bimorphism `a+b`: pairwise sums | value: `#max{V : ge(…,V)}` |
| `lmin<int>` | `le(…)` with upward closure | `x <= c` ⇒ `le(…,c)` | `#min` |
| `lset<T>` | `mem(N,R,T,k̄,X)` | `contains(x)` ⇒ `mem(…,x)`; `size >= k` ⇒ `#count{X : mem(…,X)} >= k` (monotone aggregate) | `#count{…} = n` |
| `lmap<K,𝓛>` | nest 𝓛's encoding with an extra key argument | `key?(k)` ⇒ `keyp :- ge(…,k,_)`; `at(k)` = selection by k | `#count{K : keyp(…,K)}` |
| `Lex<C chain, 𝓛>` | E-contrib: `lexc(N,T,k̄,C,enc𝓛)` | `x ⊒ (c₀, l₀)` ⇔ `∃C > c₀` ∨ (the 𝓛-threshold `l₀` over the contributions with C = c₀). **Monotone, and needs no exact max** | current key `#max{C : …}`; value = join at the max key |
| vector clock `lmap<node,lmax>` | `ge(N,vc,T,Node,V)` + closure | `vc.at(n) >= v` ⇒ atom | `not_leq(A,B) :- ge(A,…,X,V), not ge(B,…,X,V).` and `leq :- not not_leq.` (stratified) |
| keyed sum, Ross–Sagiv style (`lmap<Z, lmax<ℝ≥0>>.sum_values`) | contributions keyed by Z | `#sum{V,Z : cv(…,Z,V)} > t` (monotone: `sum+`, [AG] §5.1) | `#sum` equality |

**Async, faults and properties** (R10 A3.5(a) with the lattice rules added):
```
snd(F,D,S,R,K) :- …                                  % one per (from,to,sendtick,rel,key): merge at the sender
1 { arr(F,D,S,R,K,A) : time(A), A > S, A <= S+delta } 1 :- snd(F,D,S,R,K).   % TPLP (3)-(6) as a choice rule
% lossy mode instead: { omit(F,D,S) : snd(F,D,S,_,_), F != D, S >= 1, S < eff }. then deliver at S+1 unless omitted
ge(D,R,A,K,V) :- arr(F,D,S,R,K,A), ge(F,snd_R,S,K,V).   % arrival merges the message's atoms into the receiver's cell

```
- **Causality:** add TPLP's `before` rules (7)–(10) whenever a receiver's reply can reach the original sender inside
  the window. The Fig. 4 anomaly needs a message to arrive before it was sent, which the window A > S already rules
  out for direct sends.
- **Validated fragment, T1 (quorum):** clingo enumerates 16 counterexample runs, whose 10 minimal omission sets equal
  the brute-force LDFI result (§7).
- **Validated fragment, T9:** the 9 arrival schedules project onto exactly 2 ultimate models.

**Caveats [ours].**
- **Size.** E-atoms costs O(range) atoms per cell and time. Use E-contrib when ranges are large.
- **Grounding** grows with the horizon × nodes × keys (VER-005 bound certificates).
- **Exact reads** (`#count{…} = 1`) must stay in strata above their inputs. D7 guarantees this, and the translator
  must preserve it.

## 6. A provenance model for lattice and aggregate values

### 6.1 Annotation domain
- **Variables.** X is the set of provenance variables: message and clock variables m(from, to, t), plus optional EDB
  fact variables.
- **Annotations for set facts** live in PosBool(X), as in R06 §7.1 (Green et al. 2007).
- **Annotations for a lattice cell of type 𝓛** live in the semimodule **𝒫(𝓛) = PosBool(X) ⊗ 𝓛** ([ADT] §2.3).
  Concretely, an annotation is a finite set of **guarded values** {(φᵢ, vᵢ)}, modulo three equations:
  - (φ, v) + (ψ, v) = (φ ∨ ψ, v);
  - (φ, ⊥) = 0 and (false, v) = 0;
  - **absorption** [ours]: (φ, v) + (ψ, w) = (ψ, w) whenever φ ⊨ ψ and v ⊑ w. Both sides denote the same valuation
    function, so dominated pairs can be dropped.
- **Meaning.** eval_ν(Σ(φᵢ, vᵢ)) = ⨆{vᵢ | ν ⊨ φᵢ}, where ν is the set of surviving messages. By [ADT] Thm 3.12
  (idempotent M, +-positive K), the embedding is faithful, so the failure-free valuation recovers the actual value.

### 6.2 Propagation rules [ours; the algebra is [ADT]'s, specialized to joins]
| Operation | Annotation of the result | Exact? |
|---|---|---|
| join of derivations (merge, persistence, arrival) | sum (union of pairs, then normalize) | yes |
| rule body conjunction | multiply every guard by the ∧ of the premises' PosBool annotations | yes |
| morphism f (M) through a generator | Σ(φᵢ ∧ φ_rule, f(vᵢ)) | yes, because f(⨆S) = ⨆f(S) for non-empty S |
| morphism f through a lookup | the above, plus (φ_rule, f(⊥)) when f(⊥) ≠ ⊥ | yes |
| bimorphism g | Σ(φᵢ ∧ ψⱼ ∧ φ_rule, g(aᵢ, bⱼ)) (bilinear, like ⋈ in semiring provenance and the Flo/DBSP bilinear rule) | yes |
| monotone non-morphism h (`size`, `sum_values`) feeding a threshold | computed through the threshold's minimal supports (§6.3) | yes (for thresholds) |
| h stored in a cell | Σ over supports S of (⋀_{i∈S} φᵢ, h(⨆_{i∈S} vᵢ)), pruned by absorption | exact but exponential. **Fallback: all-contributors** (sound, coarse) |
| threshold θ | θ♯ = ⋁_{S minimal, θ(⨆_{i∈S} vᵢ)} ⋀_{i∈S} φᵢ ∈ PosBool(X). This is [ADT]'s comparison token [P ⊒ t] (§4.2), resolved inside PosBool because θ is monotone | yes |
| exact read (Anti, NM, reveal, `==`, a non-lattice aggregate) | outside the positive framework. Use Molly-style **negative support** (TEST-025): every contributor and potential contributor is a cause | conservative |
| persistence across ticks | identity (this is what Nemo's `normalize` shows) | yes |
| re-sent messages (CR-26 replay) | each send tick adds its own alternative pair: m(a,b,1) ∨ m(a,b,2) ∨ … | yes |

### 6.3 Minimal supports for thresholds

**Proposition (distributive thresholds) [ours].** Let 𝓛 be distributive, and let t ∈ 𝓛 have a finite irredundant
decomposition ⇓t = {a₁ … a_m} into join-irreducibles (R04 §5.5). Then for P = Σ(φᵢ, vᵢ):

  [eval_ν(P) ⊒ t] = ⋀_{j=1..m} ⋁_{i : aⱼ ⊑ vᵢ} φᵢ.

*Proof.* t ⊑ x iff aⱼ ⊑ x for every j. In a distributive lattice every join-irreducible is join-prime, so aⱼ ⊑ ⨆_{i∈S} vᵢ iff aⱼ ⊑ vᵢ for some i ∈ S. ∎

**LDFI consequence.** In terms of loss literals, the falsifier formula is ⋁ⱼ ⋀_{i : aⱼ ⊑ vᵢ} lost(φᵢ): **the threshold
fails iff some atom of t loses all of its contributors.** The resulting hazard DNF has one term per atom, so it is
compact and needs no CNF blow-up.

| Read | Atoms / structure | Minimal supports | Minimal falsifiers |
|---|---|---|---|
| `lmax ≥ c` | one atom {c} | each single contribution with vᵢ ≥ c | lose every such contribution (T2) |
| `lset ⊇ {e₁…e_m}` / `contains(e)` | atoms e_j | one contributor per element | for some e_j, lose all its contributors |
| `lmap.key?(k)` | a disjunction over atoms at k | any contribution with vᵢ(k) ≠ ⊥ | lose all of them (T13, with relays) |
| `lmap ⊒ {x↦3, y↦5}` (lmap<str, lmax>) | atoms {x↦3}, {y↦5} | a contributor of x ≥ 3 *and* one of y ≥ 5 | lose all contributors of one atom (T3) |
| `lbool` / `when_true` | atom tt | any tt contribution | lose all of them |
| **`size ≥ k`** on `lset` (also `majority<>`, and key counts on `lmap`) | a cardinality over elements | any k surviving elements. Element e survives iff s_e = ⋁_{i: e ∈ vᵢ} φᵢ | **Σ_e s_e ≤ k−1**, i.e. at least n−k+1 elements lose *all* their contributors (T1) |
| `sum_values > t` (non-negative, keyed) | a weighted threshold | minimal subsets of keys with total weight > t | pseudo-Boolean Σ w_z s_z ≤ t |
| non-distributive 𝓛 (e.g. `Lex` over a non-chain, a user lattice like M₃) | the proposition fails | enumerate minimal supports (exponential), or fall back to all-contributors | — |

**TEST-024 refinement.** The k-of-n rule counts **elements**, where n is the number of elements in the failure-free
value. An element may have several alternative contributors: retries, relays, several senders. Encode this with a
Tseitin variable per s_e and an at-most-(k−1) cardinality constraint. Incremental SAT with cardinality constraints, or
Z3's pseudo-Boolean support, handles this directly (TEST-028).

### 6.4 Soundness requirement for LDFI [ours, from LDFI App. B via R06 §3.8]

The hypotheses are the minimal hitting sets of the *claimed* supports.
- **Completeness (Thm B.2) survives if every claimed support is genuine**, meaning that when only it survives, the
  goal is still derived. Any real falsifier then hits every genuine support, so it satisfies the hazard formula, and
  some minimal model below it is tried.
- **Claiming a non-genuine support loses completeness.** An example would be treating `size ≥ 3` as supported by two
  votes; a real falsifier that misses the fake support would be pruned.
- **Exact supports are optimal.** Coarser genuine supports only cost extra runs. Molly's all-contributors rule for
  aggregates is genuine but coarse. On T1 it produces 5 non-falsifying single-omission hypotheses instead of the 10
  real falsifiers.

### 6.5 Explain and why-not
- **`explain (c ⊒ t)`:** return one minimal support, taking the least-height contributor per atom (ENG-111 heights).
- **`explain value(c)`:** for distributive 𝓛, return one witness contribution per atom of ⇓value(c). Otherwise return
  a minimal support of `c ⊒ value(c)`.
- **`whynot (c ⊒ t)`:** the missing atoms are {a ∈ ⇓t | a ⋢ value(c)}. For each missing atom, report why-not per
  candidate derivation or message, using TEST-051's NDERIVE / NRECEIVE / NARRIVE. For `size ≥ k`, report the
  k − |value| elements that are still needed and list the candidate elements that never arrived. For `lmax`,
  "why not ≥ c+1" is `whynot` on the atom c+1.
- **Non-lattice aggregates** (LANG-100). An exact aggregate value needs *all* contributors (Molly's rule) **and** the
  absence of any further contributor. The latter is negative support, already covered by the conservative mode. For
  explain queries, use [ADT]'s K ⊗ M annotations; ENG-114 semirings extended to semimodules.

### 6.6 Convergence of annotated fixpoints [ours]
PosBool is absorptive, and dominated pairs are absorbed (§6.1). Going around a cycle adds a pair with a stronger guard
and, when the recursion is deflation- or inflation-preserving, a dominated value (for example Trop+ path costs), so
the pair is absorbed. **Conjecture:** if the unannotated program converges for every sub-instance (every valuation ν),
the annotated iteration converges. The engine must still guard the annotated iteration with a bound and fall back to
all-contributors supports, which remain genuine, when the bound is exceeded.
