# M2.5 — SMT and ASP child-process drivers

## What was built

Added SMT-LIB2 s-expressions and typed term/sort builders, a bounded response parser with a proptest mirror and fuzz target, a `SmtSolver` child-process driver for z3 and cvc5, parsed models and named unsat cores, scoped assertions and assumptions, timeout handling that kills and reconstructs a stalled session, transcript files, solver discovery, and a clingo JSON driver with model limits and a watchdog timeout. The `libtest-mimic` conformance suite exercises all three solver binaries, and reports absent optional binaries as ignored with the requested message. `scripts/install-solvers.sh` installs pinned cvc5 1.3.3 and clingo 5.8.0 locally and is idempotent.

The full WP check, required named tests, z3-required suite, and all-solvers-required suite passed on macOS arm64 with z3 on PATH and locally installed cvc5/clingo.

## Deviations

- z3 emits a bare list of `define-fun` entries from `get-model`, while cvc5 may include the `model` tag; the parser accepts both formats.
- The watchdog is the caller's `recv_timeout` over a dedicated response-reader thread. On expiry, it kills the child and replays successful state-building commands into a new child before returning `Unknown(timeout)`. This has the same cancellation effect as a separate watchdog thread and avoids concurrent writers to the child process.
- The installer uses the cvc5 1.3.3 static release asset with pinned SHA-256. The clingo executable is a shim to the isolated venv's `python -m clingo`.
