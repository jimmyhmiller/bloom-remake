# M2.3 — blossom-syntax I

## What was built

- Hand-written UTF-8 lexer covering the LANGUAGE §2 token set, comments/trivia, numeric and string literal forms, contextual keywords, and registered lexical diagnostics.
- Recursive-descent parser for declarations, items, rule bodies, statements, specs and types; Pratt expression parser with the specified precedence; event-built lossless Rowan CST; bounded nesting and recovery with `MISSING` tokens and expected token sets.
- `blossom.ungram`, checked-in generated typed AST views, and `cargo xtask gen-ast [--check]`. The AST exposes nullable casts and accessors for the principal item, relation, handler, statement, expression and spec shapes.
- LibFuzzer target and stable proptest mirror for lossless roundtrips. Integration tests cover examples, all corpus `program.bls` files, complete LANGUAGE.md code blocks, precedence, diagnostics, recovery, typed views, and AST generation.
- Verification: `scripts/wp-check.sh blossom-syntax`, `cargo run -q -p xtask -- gen-ast --check`, and the PLAN M2.3 `scripts/require-tests.sh` filter list all passed.
