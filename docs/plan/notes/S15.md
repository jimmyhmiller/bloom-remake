# S15: floats, the browser's clock, and Flappy Bird

Goal (user, 2026-10-05): "Can we do flappy bird? compare it with the eve version as well." Floats were missing
(LANG-022); the user chose to implement f64 first rather than write the game in fixed point.

## What was built

- **The browser's clock.** The physical timer table moved from `blossom-node` to `blossom_ir::timers`, shared by
  the node and the browser host. The host runs each round at the page's time; `advance(now)` fires the timers due
  (every firing due by then, as a node does); guards are observed after every round. The page moves the clock every
  animation frame and holds it while the inspector is on. Stopwatch example; native and Playwright tests (Playwright
  drives the clock).
- **SVG and `press`.** Elements under an `svg` are made in the SVG namespace (replaced when they leave it); an element
  that is its own ancestor is a page error. `press(id)` is `pointerdown`.
- **f64 (LANG-022)**, LANGUAGE §5.1: canonical values (one zero, one NaN), IEEE arithmetic (never an error), casts
  both ways (out of range or NaN to an integer is BLSR004), constants, integer literals are not floats (the error
  says to write `2.0`), `abs`/`min`/`max`/`clamp` (also on integers: LANG-180), `sqrt`/`floor`/`ceil`/`round`/
  `trunc`/`to_string`, `rand_float`; `sum!` over f64 refused. One implementation in `blossom_value::float` for both
  evaluators. `tests/integration/tests/bls_functions.rs` runs both on random inputs against IEEE in Rust; a mutation
  (no canonicalization in the engine) fails it. TOML floats in corpus manifests and deployment parameters; floats in
  trace queries.
- **The host seeds randomness** per start (the page draws a seed from `crypto.getRandomValues`); the inspector's
  oracle replays with the same seed.
- **Flappy Bird** (`examples/web/flappy.bls`), after Eve's `flappy.eve` (v0.2.6): the same world, rules and numbers;
  physics stepped once per timer firing in a round (a fold); SVG shapes instead of sprites; the best score durable.
  Native tests (an autopilot passes obstacles; a ground-hugger hits one) and Playwright (driven clock, space bar, the
  inspector on the held game). 60 fps steady in headless Chromium (median and p95 frame 16.7–16.8 ms).
- **The comparison with Eve:** published as an artifact (side by side, block by block). Game logic is even (57
  Blossom lines vs 62 Eve); drawing is 151 vs 42, mostly one row per attribute.

## Known issues and next steps
- **Drawing is verbose**: an element-literal form lowering to `elem`/`attr` rows would bring it near Eve's size.
- **No transcendental float functions** until a deterministic implementation; `sum!` over f64 refused.
- **No corpus case for floats**: corpus ids come from the FEATURES catalog; the integration test covers both
  evaluators instead.
- **Inspector chains for per-frame state are deep** (each frame's bird derives from the previous): correct, long.
